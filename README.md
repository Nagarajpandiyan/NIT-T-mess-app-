# ESS: A Digital Solution for Streamlined Hostel Mess Management

ESS (Efficient Mess Management System) is a secure and efficient Android application developed to digitize and automate day-to-day operations of NITT hostel messes.  
It addresses key issues in communication, billing, and attendance tracking, offering a unified digital solution to enhance mess management efficiency.

---

## Features

- Secure authentication with role-based access for students and mess staff  
- Meal tracking for daily participation management  
- Attendance logging for accurate and fast record keeping  
- Automated billing management to minimize manual errors  
- Real-time notifications for announcements, menu changes, and updates  
- Intuitive, user-friendly interface for seamless interaction  

---

## Impact

- Reduced billing errors by 70%  
- Cut attendance recording time by 50%  
- Significantly improved user satisfaction  
- Adopted by over 500 students during the initial launch phase  

---

## System Architecture

The application follows a modular client-server architecture:

- **Frontend:** Android (Java / Kotlin)  
- **Backend:** Firebase (Authentication, Realtime Database, Cloud Storage)  
- **Notification System:** Firebase Cloud Messaging (FCM)  
- **Security:** Encrypted API calls and secure user sessions
